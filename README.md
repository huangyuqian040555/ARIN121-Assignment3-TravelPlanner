# ARIN121-Assignment3-TravelPlanner
An AI travel planner that helps users create personalized itineraries and compare travel destinations.

## Features
- Trip information checklist
- Day-by-day itinerary generation
- Budget adjustment
- Transportation planning
- Clarification of ambiguous destinations
- Activity selection menu
- Multi-turn destination comparison
- Activity switching with information retention

## How to Use
The assistant provides two menu options:
1. Plan a Trip
2. Compare Destinations
Users can select an activity by entering its number, name, or a request in their own words.
For trip planning, the assistant collects travel information and creates a personalized itinerary.
For destination comparison, the assistant collects destination options and travel preferences, provides an initial recommendation, and refines it based on the user's feedback.
Users can switch between activities without repeating relevant information.

## Testing
Both activities were tested in Google AI Studio Playground. The assistant successfully refined its destination recommendation and retained relevant travel information when switching activities.
